AI를 활용해서 게임 코드의 오류를 수정하고, PyInstaller를 이용해 Python으로 만든 게임을 exe 실행 파일로 변환하는 방법을 배웠다. 처음에는 게임이 Python 환경에서는 정상적으로 실행되었지만, exe 파일로 변환한 뒤에는 이미지나 사운드 파일이 불러와지지 않는 문제가 발생했다. 이를 해결하는 과정에서 개발 환경과 빌드 환경의 파일 경로 구조가 서로 다르다는 점을 이해하게 되었고, 단순히 상대 경로만 사용하는 방식에는 한계가 있다는 것을 알게 되었다. 특히 PyInstaller가 실행 파일 내부에 리소스를 압축해 저장하기 때문에 기존 경로 방식이 그대로 동작하지 않는다는 점이 인상적이었다.

이 문제를 해결하기 위해 resource_path() 함수를 사용하는 방법을 배웠다. 이 함수를 활용하면 Python 코드 실행 환경과 exe 빌드 환경 모두에서 동일한 방식으로 이미지, 사운드, 폰트 파일 등을 안정적으로 불러올 수 있었다. 단순히 오류를 수정하는 것에 그치지 않고, 프로그램이 실행되는 환경에 따라 파일 시스템 구조가 달라질 수 있다는 점을 이해하게 되면서 프로그램 배포 과정에 대한 시야도 넓어졌다. 또한 게임 개발에서는 코드뿐만 아니라 리소스 관리 역시 매우 중요하다는 사실을 배웠다.

PyInstaller 명령어를 사용해 실행 파일을 만드는 과정도 흥미로웠다. --onefile, --windowed, --add-data 같은 옵션이 각각 어떤 역할을 하는지 알게 되었고, 필요한 리소스를 함께 포함시키는 방법도 익혔다. 특히 파일 이름이나 경로에 공백이 있을 경우 따옴표를 사용해야 한다는 점, 운영체제에 따라 경로 구분 방식이 달라질 수 있다는 점 등 실제 배포 과정에서 자주 발생하는 문제들도 경험할 수 있었다. 이런 세부적인 부분들은 단순히 코드를 작성할 때는 잘 드러나지 않지만, 프로그램을 다른 사람에게 배포할 때 매우 중요하다는 것을 깨달았다.
