AI를 활용해서 게임 코드의 오류를 수정하고, PyInstaller를 이용해 게임을 exe 파일로 만드는 방법을 배웠다.
특히 이미지와 사운드 파일이 exe 환경에서 경로 오류가 발생하는 이유를 이해했고, resource_path() 함수를 사용하면 개발 환경과 빌드 환경 모두에서 정상적으로 파일을 불러올 수 있다는 것을 알게 되었다.

또한 PyInstaller 명령어를 사용해 Python 게임을 실행 파일로 변환하는 방법과, 파일 이름에 공백이 있을 경우 따옴표를 사용해야 한다는 점도 배웠다.
AI의 도움을 받아 오류 원인을 빠르게 찾고 해결할 수 있었고, 게임 배포 과정을 더 쉽게 이해할 수 있었다.
